## 2. СТИЛЬ НАПИСАНИЯ: ДМИТРИЙ СОКОЛОВ-МИТРИЧ

### Кто это

### Ключевые приёмы, которые мы используем
- **Авторское «я»** - не «мы», а «я залез в данные», «я посмотрел». Всегда от первого лица
- **Рубленый ритм** - короткие предложения чередуются с длинными. Факт. Ещё факт. Вывод. Потом длинное размышление
- **Метафоры из жизни** - кардиограмма пациента (про график), театр и аплодисменты (про запуск), ресторан с одним блюдом (про блеск без LTV), цифровая барахолка (про 19 продавцов), рентген (про аналитику), вспышка (про первый месяц)
- **Ирония без злости** - не разоблачение, а рентген. «Бездарности не набирают 7 миллионов подписчиков»
- **«Не надо никого жалеть»** - честность, но без жестокости. Сначала уважение к герою, потом правда
- **Переходы как мысли** - «А теперь - факт, ради которого стоило садиться за эту статью», не «Раздел 3»
- **Кольцевая композиция (Гладуэлл)** - факт про Rhode в середине + возврат как риторический вопрос в финале
- **Заголовки** - короткие (2-5 слов), с парадоксом или метафорой. Никаких цифр в заголовках разделов. Цифры внутри текста
- **Без длинных тире** - заменены на короткие тире или двоеточия. Длинные тире «пахнут нейросетью»
- **Без эмодзи** - весь проект выдержан без эмодзи

### Книги для изучения стиля (рекомендовали Алмасу)
1. Соколов-Митрич «Реальный репортёр» - методичка

ForteBank рекламирует себя как площадку для селлеров + даёт кредиты. Но: трафика на ForteMarket нет, скоринг без API маркетплейса (только по банковским выпискам).

### Личный опыт Алмаса
- Просил 20 млн, дали 8
- Не спросили API, не запросили данные по продажам
- Скоринг по выпискам = «диагноз по фотографии»

### Контекст
- Альфа-Банк купил Market Guru, другие банки подключают MPStats - для качественного скоринга
- Алпамыс (основатель Go-Crowd) не знал, что такое API маркетплейсов
- Redstat интегрируется с Most Finance (в процессе)

### Стратегия: рилз → статья → рилз
1. Рилз-провокация (личный опыт + факт про российские банки)
2. CTA: «Напишите в комментариях, что думаете. Если тема зайдёт - сделаю полный разбор»
3. Статья через неделю с данными
4. Второй рилз со ссылкой

### Данные для сбора
- SimilarWeb: market.forte.kz vs kaspi.kz (витрины покупателей)
- SimilarWeb: seller.forte.kz vs idmc.shop.kaspi.kz (селлерские кабинеты)
- Data.ai / Google Play: скачивания приложений
- ForteMarket в Facebook: 1 916 лайков (ноль для маркетплейса)

### Фраза-тизер для рилз
«Мы решили не болтать, а сделать» - тизер интеграции с Most Finance без деталей

## 17. КЛЮЧЕВЫЕ РЕШЕНИЯ И ПРИНЦИПЫ

- Без авторизации на сайте - максимальная доступность
- Без комментариев на сайте - обсуждение в Telegram
- ChatPlace, не ManyChat - проще, дешевле, СНГ
- Сначала тред → потом рилз (для Lick Beauty)
- Сначала рилз → потом статья (для ForteBank)
- Один рилз - один CTA (не размывать)
- Не удалять контент под давлением героев
- Смягчать форму, не содержание
- Каждый тезис подкреплён данными и ссылками
- «Рентгену всё равно, нравишься ты ему или нет» - сквозная фраза проекта
